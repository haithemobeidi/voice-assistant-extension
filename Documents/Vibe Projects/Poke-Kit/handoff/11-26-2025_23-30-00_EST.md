**Sprite Fallback System (pokemonLoader.ts:70-116):**
```typescript
const LEGENDS_ZA_MEGA_FALLBACKS: Record<string, number> = {
  'clefable-mega': 36,
  'dragonite-mega': 149,
  // ... all 26 new megas mapped to base form dex numbers
};

export function getSpriteUrl(pokemon: { name: string; id: string; number: number }): string {
  const baseUrl = 'https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/other/official-artwork';
  const fallbackNumber = LEGENDS_ZA_MEGA_FALLBACKS[pokemon.name];
  if (fallbackNumber) {
    return `${baseUrl}/${fallbackNumber}.png`;
  }
  return `${baseUrl}/${pokemon.id}.png`;
}
```

**Design Decisions:**
- Used base form sprites as fallback since official Z-A sprites aren't in PokeAPI/Showdown yet
- Assigned IDs starting at 10278 (after max existing ID 10277)
- Set `hasShiny: false` and `hasCry: false` for new forms
