## Technical Notes

**Card Flip Implementation:**
```css
.pokemon-card-container { perspective: 1000px; }
.pokemon-card-inner {
  transition: transform 0.5s ease-out;
  transform-style: preserve-3d;
}
.pokemon-card-container.flipped .pokemon-card-inner {
  transform: rotateY(180deg);
}
.pokemon-card-front, .pokemon-card-back {
  backface-visibility: hidden;
}
.pokemon-card-back { transform: rotateY(180deg); }
```

**Infinite Scroll:**
```typescript
infiniteScrollObserver = new IntersectionObserver(
  (entries) => {
    if (entry.isIntersecting) loadMorePokemon();
  },
  { rootMargin: '200px', threshold: 0 }
);
```
