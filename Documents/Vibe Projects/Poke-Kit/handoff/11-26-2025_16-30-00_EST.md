## Technical Notes

**Data Sources Used:**
- Bulbapedia for gym leader teams (levels, moves, version differences)
- Bulbapedia for Elite Four and Champion teams
- Manual compilation for Pokémon availability per progression point

**Architecture:**
- JSON data files imported directly (no API calls needed)
- State managed with module-level variables (selectedGame, selectedBoss)
- Renders via template literals, re-renders on selection change
- Type colors defined locally to avoid import complexity
