## Technical Notes

**Moveset Modal Architecture:**
- `openMovesetModal()` - Opens modal, fetches moves from PokeAPI
- `fetchPokemonMoves()` - Fetches and caches move data by Pokemon
- `processPokeApiResponse()` - Parses PokeAPI move data into MovesByGen structure
- `renderMoves()` - Renders moves for selected generation
- `fetchAndUpdateMoveTypes()` - Lazy-loads move type colors in batches of 10
- Move type cache prevents redundant API calls

**Type Matchup Modal Architecture:**
- `openMatchupModal()` - Opens modal, calculates defensive profile
- `getFullDefensiveProfile()` - Returns matchups with multipliers
- `renderMatchups()` - Groups by multiplier and renders sections
- `renderMatchupSection()` - Creates type badges with watermark icons
