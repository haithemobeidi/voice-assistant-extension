### Key Code Changes:

**pokemonLoader.ts** - New shared lazy loader:
```typescript
let cachedPokemonData: PokemonCreature[] | null = null;
let loadPromise: Promise<PokemonCreature[]> | null = null;

export async function loadPokemonData(): Promise<PokemonCreature[]> {
  if (cachedPokemonData) return cachedPokemonData;
  if (loadPromise) return loadPromise;

  loadPromise = (async () => {
    const response = await fetch('/data/pokemon.json');
    cachedPokemonData = await response.json();
    return cachedPokemonData;
  })();

  return loadPromise;
}
```

**All consumers now async:**
```typescript
// Before
import pokemonData from './data/pokemon.json';
export function initPokedex(): void { ... }

// After
import { loadPokemonData } from './shared/pokemonLoader';
export async function initPokedex(): Promise<void> {
  const pokemonData = await loadPokemonData();
  ...
}
```

## Technical Notes

**Why Code Splitting Works:**
- pokemon.json (789KB) was bundled into main JS chunk
- Now fetched on-demand only when Pokédex/Teams/Nicknames pages are visited
- Shared cache ensures single fetch even if multiple pages use the data
- Initial page load much faster - main JS is only 126KB

**Loading States:**
- Each page shows "Loading Pokémon data..." spinner during fetch
- Error handling with "Retry" button if fetch fails
- Graceful degradation for network issues

**Caching Strategy:**
- Single in-memory cache shared across all consumers
- loadPromise prevents duplicate concurrent fetches
- Data persists for entire session (no re-fetch on navigation)
