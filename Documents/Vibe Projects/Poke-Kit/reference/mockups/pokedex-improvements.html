Pokédex Improvements Mockup

Three key improvements: Infinite scroll, better variant display, full stat breakdown

Infinite Scroll (Auto-load on scroll)

Problem: Currently requires clicking "Load More" button repeatedly.
Solution: Auto-load more Pokémon when user scrolls near bottom of the list.

Implementation:

  • • Use Intersection Observer API to detect when user reaches bottom
  • • Load 20 more cards automatically
  • • Show loading spinner while fetching
  • • Keep "Load More" as fallback option
